INFORMATION
----------------------

Pajitaraptor 2.0 es un robot siguelineas evolución de Pajitaraptor. La idea es hacer un robot siguelineas lo más rápido posible con los componentes que tengo actualmente.

En este repositorio, voy a poner todos los archivos 3D, código fuente , esquemáticos, fotografías y vídeos explicativos del proceso de construcción del robot. 

Si el robot funciona bien, en el futuro realizaré una PCB, para que sea más fácil replicarlo...
